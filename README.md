# One Star for Monday

A one-star review of Monday, written as if Monday were a restaurant. One line, plain text — no hashtags, no stage directions, no explanation.

## Run

```sh
node main.ts
```

`main.ts` reads `line.txt` in the same directory, validates it (1–180 characters, a single non-blank line, at most 25 words), and writes the exact same bytes — with no trailing newline — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the environment variable is not set).
